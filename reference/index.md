# Package index

## Moments of order statistics

The exact means, variances and covariances at any ranks and any sample
size, for five built-in families or a user-supplied distribution.

- [`os_moments()`](https://zwulab.github.io/osmoments/reference/os_moments.md)
  : Exact moments of order statistics
- [`os_dist()`](https://zwulab.github.io/osmoments/reference/os_dist.md)
  : Define a distribution for the moments of its order statistics
- [`print(`*`<osmoments>`*`)`](https://zwulab.github.io/osmoments/reference/print.osmoments.md)
  : Print an osmoments object

## Sample quantiles, linear combinations and the BLUE

The linear layer over the moments.

- [`os_quantile_weights()`](https://zwulab.github.io/osmoments/reference/os_quantile_weights.md)
  : Ranks and weights of the sample quantile definitions
- [`os_lin_moments()`](https://zwulab.github.io/osmoments/reference/os_lin_moments.md)
  : Moments of linear combinations of order statistics
- [`os_blue()`](https://zwulab.github.io/osmoments/reference/os_blue.md)
  : Lloyd's best linear unbiased estimators of location and scale
